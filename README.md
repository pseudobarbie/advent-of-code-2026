# 🎄 Advent of Code 2026

> *The Chief Historian is missing. The North Pole is in chaos. Again.*

My chronicle of the 2026 expedition — twenty-four stars, countless cups of mint tea,
and the occasional 3 AM epiphany. Standard library only, one small runner, no ceremony.

**On the calendar.** Since 2025 the event runs **twelve days rather than twenty-five**, and
the global leaderboard is gone. Eric Wastl [explained why](https://adventofcode.com/2025/about):
building twenty-five original puzzles a year had stopped being sustainable, and LLMs had
made the speed leaderboard meaningless anyway. Fewer doors on the calendar, same cold air.
If 2026 reverts, change `DAYS` at the top of `aoc.py` and the rest follows.

## ⚡ Quick start

```bash
git clone https://github.com/YOUR_USERNAME/advent-of-code-2026.git
cd advent-of-code-2026
cp .env.example .env          # paste your session cookie in

python aoc.py new 1 --title "Historian Hysteria"
python aoc.py fetch 1
python aoc.py run 1 --example
python aoc.py run 1
python aoc.py stats
```

Python 3.10 or newer. Nothing to install.

### Commands

| Command | What it does |
|:--|:--|
| `aoc.py new DAY` | Scaffold a day from the template. Takes `--title`, `--force`. |
| `aoc.py fetch DAY` | Download your input to `inputs/`. Cached — only ever hits the server once. |
| `aoc.py run DAY` | Both parts, with timings. Takes `--example`, `--part 1\|2`. |
| `aoc.py run all` | Every day written so far, skipping ones with no input. |
| `aoc.py stats` | Refresh the progress table and badge. `--run` re-runs everything first. |

### Fetching input by hand

If you'd rather not hand a script your session cookie:

```bash
export AOC_SESSION=your_session_cookie_here
curl -s "https://adventofcode.com/2026/day/1/input" \
  -H "Cookie: session=$AOC_SESSION" \
  -H "User-Agent: github.com/YOUR_USERNAME/advent-of-code-2026" \
  -o inputs/day01.txt
```

## 🧩 Anatomy of a solution

Two functions, both handed the raw puzzle text as a string:

```python
"""Day 1: Historian Hysteria

https://adventofcode.com/2026/day/1
"""

from collections import Counter


def parse(data: str) -> tuple[list[int], list[int]]:
    left, right = zip(*(map(int, line.split()) for line in data.splitlines()))
    return sorted(left), sorted(right)


def part1(data: str):
    left, right = parse(data)
    return sum(abs(a - b) for a, b in zip(left, right))


def part2(data: str):
    return None   # unsolved — the runner records no star
```

Trailing newlines are stripped before `data` arrives; nothing else is touched. Returning
`None` means unsolved. A part that raises gets caught and reported, and the other part
still runs.

## 🎨 Ground rules

| Principle | Why |
|:--|:--|
| 🧊 Clarity over cleverness | If it needs a comment to explain *what* it does, rewrite it. |
| ❄️ Example first | Nothing touches real input until it clears the sample. |
| 🌲 Time everything | The runner reports both parts. Anything past a second gets a second look. |
| 🔔 Standard library only | No solvers, no puzzle-specific packages. The journey beats the finish. |
| 🕯️ Keep the wreckage | When part two demolishes part one's architecture, both live in git history. |
