## 🧭 The Expedition

&gt; *"The Chief Historian has gone missing. Again."*

Every December, the elves at the [North Pole](https://adventofcode.com/2026) face a new crisis—one that can only be solved by parsing logs, traversing grids, and optimizing reindeer flight paths. This repository chronicles my journey through the **2026** edition of Advent of Code.

Each day's puzzle is a self-contained story, a small world of logic waiting to be untangled. Some days demand brute force; others whisper of dynamic programming. All of them reward curiosity.

## 🏛️ Repository Structure

```text
advent-of-code-2026/
│
├── 📁 day01/                    # Each day is self-contained
│   ├── 📄 main.rs               # Entry point (parts 1 & 2)
│   ├── 📄 lib.rs                # Core logic & algorithms
│   ├── 📄 example.txt           # Provided sample input
│   ├── 📄 input.txt             # Personal puzzle input (gitignored)
│   └── 📄 README.md             # Day notes, insights, complexity analysis
│
├── 📁 day02/
├── 📁 day03/
│   ...
│
├── 📁 shared/                   # Common utilities across days
│   ├── 📄 grid.rs               # 2D grid helpers, Point structs
│   ├── 📄 parser.rs             # Combinator-based input parsing

│   └── 📄 lib.rs
│
├── 📁 scripts/
│   ├── 📄 scaffold.sh           # `cargo new`-style day generator

│

│   └── 📁 workflows/
│       └── 📄 ci.yml            # Run tests & clippy on every commit
│
├── 📄 Cargo.toml                # Workspace manifest
